# Для тебя ❤️ — сайт-письмо

Шесть разделов, между которыми переход по кнопкам и по полосе шагов сверху:

| № | Раздел | Файл | Что внутри |
|---|--------|------|------------|
| 1 | «Я никогда не забуду твои подарки» | `index.html` | 7 фото + маршрут по сайту |
| 2 | «Я никогда не забуду твои укусы» | `page2.html` | 8 фото |
| 3 | «Я никогда не забуду твои влюблённые глаза, которые горели» | `page3.html` | 3 фото |
| 4 | «Наша переписка в цифрах» | `page5.html` | живая статистика из Telegram |
| 5 | «Нажми, если взгрустнулось» | `page6.html` | 18 фраз, кнопка со сердечками |
| 6 | «Всё, что я хочу тебе сказать» | `page4.html` | письмо + 3 кадра (финал) |

Плюс `love_site_one_file.html` — **все 6 разделов в одном файле**: стили, скрипты и все фото внутри.
Такой файл можно переслать одним сообщением и открыть на телефоне даже без интернета
(кроме статистики: для неё нужен интернет и работающий `stats_service`).

## Структура

```
love_site/
├── index.html · page2.html · page3.html · page5.html · page6.html · page4.html
├── styles.css               весь дизайн
├── script.js                лайтбокс, переходы, статистика, кнопка от грусти
├── build_one_file.py        сборка love_site_one_file.html
├── love_site_one_file.html  ← версия «всё в одном файле»
├── photos/                  оригиналы фотографий (не изменялись)
└── img/                     веб-версии (латиница, сжатые)
    ├── gift_01..07.jpg      подарки
    ├── bite_01..08.jpg      укусы
    ├── eyes_01..03.jpg      глаза
    └── large/               те же кадры крупнее — для лайтбокса
```

## Что умеет

- **Кнопки «Назад» / «Дальше»** на каждой странице + кликабельная полоса шагов.
- **Лайтбокс**: клик по фото — крупный кадр; стрелки `←` `→`, свайпы, `Esc` — закрыть.
- **Статистика переписки** (страница 4): если сервис ещё не подключён к Telegram, страница
  покажет причину и кнопку-ссылку на страницу входа сервиса (`/login`), где вход делается
  QR-кодом с телефона. Числа забираются с сервиса `stats_service`
  при каждом заходе и обновляются каждые 45 секунд. Если сервис спит или ещё не получил
  доступ к Telegram, страница по очереди подставляет: `stats.json` из выгрузки →
  последние известные цифры из кэша телефона → понятное объяснение, что именно не настроено.
  Поэтому пустой страница не бывает никогда.
- **Кнопка от грусти** (страница 5): случайная фраза без повторов, счётчик нажатий
  хранится в телефоне, при клике разлетаются сердечки.
- **Адаптив**: на телефоне фото в 2 колонки, шаги превращаются в кружки.
- При системном «уменьшить движение» анимации выключаются.

## Как менять

- **Текст** — прямо в HTML-файлах. Фразы кнопки — блок `id="phrases"` в `page6.html`.
- **Адрес сервиса статистики** — строка `STATS_API_DEFAULT` в самом верху блока
  `Статистика переписки` в `script.js` (сейчас там `https://i-love-you-anya.onrender.com`).
  Можно переопределить без правки кода: открыть страницу как
  `.../page5.html?api=https://твой-адрес` — адрес запомнится в браузере.
- **Запасные цифры** — файл `stats.json` в этой папке (делается скриптом
  `stats_service/from_export.py` из выгрузки Telegram).
- **Фото** — положить в `img/` и добавить блок:

  ```html
  <figure class="shot" tabindex="0" role="button">
      <img src="img/gift_08.jpg" data-full="img/large/gift_08.jpg" alt="Твой подарок">
      <figcaption class="num">08</figcaption>
  </figure>
  ```

  Нет файла в `img/large/` — убери атрибут `data-full`, лайтбокс возьмёт `src`.
- **Цвета** — переменные `--pink`, `--violet`, `--cyan` в начале `styles.css`.
- После правок пересобрать одностраничную версию: `python3 build_one_file.py`.

## Как открыть

- Локально: `python3 -m http.server` в этой папке → <http://localhost:8000>.
- Телефон / пересылка: `love_site_one_file.html`.
- Хостинг: см. `../DEPLOY.md` (Render, Cloudflare Pages, GitHub Pages, свой домен).
